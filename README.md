# 🪶 Kestrel

**A transaction-intelligence command center — built end-to-end by an AI agent fleet.**

Kestrel is a live fraud-detection demo: synthetic payments stream between world financial hubs on a 3D globe, fraud patterns light up in red, and KPI tiles tick in real time. It is aimed at a bank/fintech executive audience — and it is also the stage for a different demonstration entirely: every feature after the initial scaffold is planned, built, tested, and reviewed by Claude Code agents, and the site's `/fleet` page visualizes that history from this repo's own PRs.

> **All data is simulated.** Every transaction, city, amount, and fraud event is generated by a deterministic simulation engine. Nothing here is real financial data.

## How it works

- **Deterministic world**: every event is a pure function of `(GLOBAL_SEED, time bucket)`. The browser and the Worker compute the identical stream — every viewer, everywhere, sees the same world at the same moment, with no backend state at all.
- **One Worker**: React 19 + Vite + Tailwind v4 frontend served as static assets; a Hono API on Cloudflare Workers behind `/api/*`. One build, one deploy.
- **Agent fleet**: issues are decomposed by a planner agent, implemented by builder agents, verified by tester and reviewer agents. PRs carry `agent:*` labels; merge auto-deploys; `/fleet` renders the evidence.

## Stack

TypeScript end-to-end · React 19 · Vite · Tailwind v4 · Hono · Cloudflare Workers (static assets + API) · Biome · Vitest (`unit` pool + workers pool in real workerd) · GitHub Actions (CI, PR preview URLs, deploy on merge)

## Develop

```sh
pnpm install
pnpm dev     # dev server with the Worker running in workerd
pnpm check   # biome + tsc + vitest — the CI gate
```
